# 发布前 QA 检查清单

适合小型网页产品或 API 的快速发布前检查。每项标记“通过”“失败”或“不适用”，每个失败项附上一条可复核证据。

## 1. 构建与访问

- [ ] 记录测试构建、环境和版本号或提交号。
- [ ] 记录支持的浏览器、设备和 API Base URL。
- [ ] 测试账号和样例数据可用，且不含生产环境密钥。
- [ ] 入口页面使用预期协议加载并正确跳转。

## 2. 关键用户流程

- [ ] 新用户可以到达第一个可用页面。
- [ ] 注册、登录、退出和找回密码符合预期。
- [ ] 必填项能拒绝空值或格式错误，并给出有用提示。
- [ ] 成功操作会明确确认，并产生预期状态变化。
- [ ] 刷新、返回、重复提交和会话过期不会破坏状态。

## 3. API 冒烟检查

- [ ] 使用有效和无效凭据检查认证与授权。
- [ ] 必填参数、错误类型和不存在资源返回已记录的错误。
- [ ] 状态码、响应头、结构和代表性字段与文档一致。
- [ ] 分页、筛选和空结果在支持时表现一致。
- [ ] 日志、错误信息和示例响应不泄露敏感值。

## 4. 证据与发布判断

每个失败项记录：

1. URL 或接口端点及请求上下文。
2. 精确复现步骤。
3. 预期行为和实际行为。
4. 严重程度和用户影响。
5. 浏览器/设备或 API 客户端信息。
6. 截图、响应正文或短视频。

发布前确认严重问题都有负责人、复测结果和明确处理决定。无法复现时记录环境和下一步诊断，不要直接关闭问题。
